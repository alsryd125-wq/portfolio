# 퍼포먼스 마케터 이민경 포트폴리오

데이터 기반의 사고와 유연한 소통을 지향하는 퍼포먼스 마케터 이민경의 웹 포트폴리오입니다.

## 구성

- **About**: 경력, 프로젝트 이력, 스킬
- **Selected Work**: 브랜드별 카드를 클릭하면 프로젝트 상세(전략 · 성과)가 열립니다
  - 메노킨 JP · 스토어허브 · 지누스 · 샤크닌자 · 디스커버리 · 신규 광고주 비딩
- **Creative Planning**: 브랜드별 소재 기획 사례

## 파일 구조

```
index.html        페이지 본문 (HTML · CSS · JS 한 파일)
assets/           이미지 (로고, 소재, 프로젝트 캡처, 아이콘)
.nojekyll         GitHub Pages가 파일을 그대로 서비스하도록 하는 설정
```

빌드 과정 없이 `index.html`을 브라우저로 열면 바로 볼 수 있습니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 선택합니다.
3. 몇 분 뒤 `https://<GitHub 아이디>.github.io/<저장소 이름>/` 주소로 접속할 수 있습니다.
