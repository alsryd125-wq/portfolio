# 이민경_퍼포먼스 마케터_포트폴리오

데이터로 매체·예산·입찰·소재를 최적화하고 ROAS로 증명하는 퍼포먼스 마케터 이민경의 웹 포트폴리오입니다.

## 포트폴리오 주소

| 이름 | 주소 | 폴더 |
|---|---|---|
| **이민경_퍼포먼스 마케터_포트폴리오** (공용) | https://alsryd125-wq.github.io/portfolio/performance-marketer/ | `performance-marketer/` |
| 프롬랩스 지원용 | https://alsryd125-wq.github.io/portfolio/fromlabs/ | `fromlabs/` |
| 최초 버전 | https://alsryd125-wq.github.io/portfolio/ | `index.html` |

`v2/`, `fromlabs-performance/`는 예전 링크를 새 주소로 넘겨주는 이동 페이지입니다.

## 구성

- **About**: 경력, 프로젝트 이력, 운영 매체, 스킬
- **Selected Work**: 브랜드별 카드를 클릭하면 프로젝트 상세(Overview · Strategy · Result)가 열립니다
  - 메노킨 JP · 스토어허브 · 지누스 · 샤크닌자 · 디스커버리 · 신규 광고주 비딩
- **Creative Planning**: 소재 기획 프로세스와 브랜드별 소재 사례

## 파일 구조

```
performance-marketer/index.html   이민경_퍼포먼스 마케터_포트폴리오 (공용)
fromlabs/index.html               프롬랩스 지원용
index.html                        최초 버전
assets/                           모든 버전이 함께 쓰는 이미지
```

빌드 과정 없이 HTML 파일을 브라우저로 열면 바로 볼 수 있습니다.
